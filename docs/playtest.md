# 🥊 Fight Club — 플레이테스트 진행 안내 (P7-5)

공개 전에 8~16명이 스테이징에서 함께 싸워 보며 **재미·공정함·렉 체감**을 확인하고 밸런스 값을 조정한다.
결과(설문·조정값)는 [설계서 §14 변경 기록](design.md)과 [워크플로](../claudedocs/workflow_fight-club.md)에 남긴다.

## 준비 (진행자)

| 할 일 | 방법 |
|---|---|
| 스테이징 주소 | `https://<SITE>` ([배포 안내](../deploy/README.md)). 참가자는 **PC 브라우저**(Chrome·Edge·Firefox·Safari 최신)로 — 휴대폰 조작은 아직 없다 |
| 같은 곳에서 여럿이 할 때 | 같은 공유기(사무실·집) 뒤의 사람들은 공인 IP가 하나라 **동시 3명 제한**에 걸린다. 그 공인 IP를 서버 `.env`의 `IP_LIMIT_EXEMPT`에 넣고 반영한다 — 끝나면 지운다 |
| 운영 화면 | `https://<SITE>/admin`을 띄워 두고 접속자·틱 처리 p95·CPU를 본다 |
| 로그 | `deploy/logs.sh ubuntu@<IP>` — `"level":50`(오류) 줄이 나오면 시각과 함께 적어 둔다 |
| 시간 | 40분: 안내 5 · 자유 대전 15 · 상황 시험 10 · 설문 10 |

## 진행

1. **안내 (5분)** — 화면 아래 키 그림과 H(조작법)를 보여 준다. 목표는 킬과 생존. 이상한 것을 보면 **시각과 상황**을 메모해 달라고 한다.
2. **자유 대전 (15분)** — 사람이 많은 경기장에 먼저 들어가므로, 차례로 입장하면 16명까지 한 경기장에 모인다.
3. **상황 시험 (10분)** — 둘씩 짝지어 아래 상황을 한 번씩 해 본다.
4. **설문 (10분)** — 아래 문항.

### 상황 시험

| 상황 | 볼 것 |
|---|---|
| 가드한 상대에게 기본·특수·발차기 | 막았을 때 피해(20%)와 밀림이 적당한가, 가드가 너무 세지 않은가 |
| 가드한 상대를 잡아서 가장자리로 던지기 | 잡기가 가드를 깨는 수단으로 쓸 만한가, 던지기(5m)로 떨어지는 것이 과하지 않은가 |
| 연속으로 4번 맞기 | 다운까지가 너무 빠르거나 느리지 않은가, 기상 무적(1초) 뒤 다시 싸울 만한가 |
| 달리며 공격(돌진) · 점프 중 발차기(날아차기) | 쓸 만한가, 너무 센가 |
| 가장자리 싸움 | 낙사가 너무 잦거나 드문가 — 경기장 크기(24m) |
| 멀리 사는 사람과 대결 | 렉 체감: 화면에서는 피했는데 맞았다는 느낌이 자주 드는가 |
| 혼자 들어가 봇 3명과 | 재미있는가, 봇이 너무 세거나 약한가 |

### 설문 (1~5점 + 한 줄)

1. 때릴 때 손맛(타격감)이 있었나
2. 조작이 금방 손에 익었나
3. 억울하게 맞았다고 느낀 적이 있나 (어떤 상황)
4. 끊기거나 늦게 반응한다고 느꼈나
5. 가장 센 기술 / 가장 쓸모없는 기술
6. 경기장 크기는 (좁다 · 적당 · 넓다)
7. 다시 하고 싶은가
8. 버그·이상한 점 (자유)

## 조정할 수 있는 값

값을 바꾸면 그 값을 고정해 둔 테스트도 함께 고친다 (`npm test`). 설계 근거는 설계서 §4.

| 무엇 | 파일 | 지금 값 |
|---|---|---|
| 공격 프레임·피해·넉백 | `shared/src/attacks.ts` `ATTACKS` | 잽 선딜 5·피해 5·넉백 0.4m, 스트레이트 8·8·1.0m, 발차기 14·12·2.5m, 돌진 6·12·2.5m |
| 쿨타임 | `shared/src/attacks.ts` | 발차기 `KICK_COOLDOWN` 180프레임(3초), 잡기 `GRAB.cooldown` 5초 |
| 던지기 | `shared/src/attacks.ts` `THROW` | 피해 10, 넉백 5m |
| 이동·점프 | `shared/src/constants.ts` | 걷기 4m/s, 달리기 6.5m/s, 점프 7m/s, 중력 20m/s² |
| 넉백 감속 | `shared/src/constants.ts` `KNOCKBACK_DECEL` | 20m/s² |
| 경기장 크기 | `shared/src/constants.ts` `ARENA_HALF` | 12 (24m × 24m) |
| 가드 | `shared/src/constants.ts` | 피해 `GUARD_DAMAGE_RATE` 0.2, 밀림 `GUARD_KNOCKBACK_RATE` 0.3, 정면 140° |
| 연속 피격 다운 | `shared/src/constants.ts` | 1.5초 안에 4번 (`COMBO_KNOCKDOWN_HITS`·`COMBO_WINDOW_FRAMES`) |
| 입장 무적·낙사 킬 인정 | `shared/src/constants.ts` | 3초 (`SPAWN_INVULN_FRAMES`), 맞고 5초 안 (`RINGOUT_CREDIT_FRAMES`) |
| 봇 | `server/src/bots/brain.ts` `BOT` | 반응 0.25~0.45초, 공격 비율 잽 50·스트레이트 30·발차기 20, 가드 30%, 잡기 20% |

조정한 뒤에는 `npm test` → 커밋 → `deploy/ship.sh`로 스테이징에 올려 다시 해 본다.
