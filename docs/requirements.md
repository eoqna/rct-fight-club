## 1. 개요

### 1.1 한 줄 요약
로그인 없이 브라우저로 접속해 3D 캐릭터를 고르고 랜덤 인디언식 닉네임을 받은 뒤, 같은 경기장에 있는 사람들과 펀치·발차기로 싸우는 **실시간 멀티플레이 3D 난투 게임**. HP가 0이 되거나 경기장 밖으로 떨어지면 탈락해 튕겨나간다.

### 1.2 목표
- **가벼운 진입**: 접속하고 몇 초 안에 싸움에 뛰어든다.
- **쉬운 조작, 확실한 손맛**: 키 몇 개만으로 때리고, 막고, 잡아 던진다.
- **낙사의 긴장감**: 가장자리에서 밀어내고 버티는 싸움.
- **이름이 주는 웃음**: 랜덤 닉네임이 킬 피드에서 웃음 포인트가 된다.

### 1.3 대상 사용자
- 불특정 다수의 웹 방문자 (가입 없음, 익명)
- PC(키보드) 사용자와 모바일(터치) 사용자 — 같은 경기장에서 함께 싸운다

### 1.4 현재 저장소 상태
- Vite + React 19 + TypeScript 기본 템플릿 (게임 코드·서버 없음)
- `package.json`의 이름이 `claw-machine` → 프로젝트명 정리 필요

## 3. 사용자 흐름

시작 화면 → 캐릭터 선택·닉네임 생성 → 경기장 자동 배정·입장 → 전투 → 탈락 (HP 0 · 낙사 · 자리 비움) → 결과 화면 → 캐릭터 선택으로 돌아감

## 4. 기능 요구사항

### 4.1 시작·입장
- **FR-01** 회원가입·로그인 없이 시작할 수 있다.
- **FR-02** 시작 화면에 게임 제목, 현재 전체 접속자 수, 시작 버튼, 조작법 보기를 표시한다.
- **FR-03** '입장'을 누르면 빈자리가 있는 경기장 중 **사람이 가장 많은 곳**에 자동 배정한다.
- **FR-04** 모든 경기장이 꽉 차면 새 경기장을 자동으로 만든다.
- **FR-05** 게임 화면에 경기장 번호와 인원을 표시한다 (예: `경기장 #3 · 12/16`).

### 4.2 캐릭터 선택
- **FR-06** 프리셋 캐릭터 4~6종을 3D로 돌려 보며 고를 수 있다.
- **FR-07** 모든 캐릭터는 HP·속도·공격력이 같고 외형만 다르다.
- **FR-08** 같은 캐릭터를 여러 명이 고를 수 있다. *(제안)* 같은 캐릭터끼리 구분되도록 색상 변형을 준다.

### 4.3 닉네임 (인디언식 이름)
- **FR-09** 닉네임은 **[형용사] + [자연 명사] + [어미구]**를 랜덤으로 조합해 만든다.
  - 예: 용감한 늑대의 기상 · 조용한 태양과 함께 춤을 · 푸른 달빛은 그림자 속에 · 백색 매와 함께 춤을
- **FR-10** 받침 유무에 따라 조사를 자동으로 고른다 (와/과, 은/는, 이/가, 을/를).
- **FR-11** 입장 전에 🎲 버튼으로 몇 번이든 다시 뽑을 수 있다. 직접 입력은 받지 않는다 (욕설 필터 불필요).
- **FR-12** 같은 경기장에 같은 이름이 있으면 자동으로 다시 만든다.
- **FR-13** 만들 수 있는 이름 조합은 1,000개 이상이어야 한다.

### 4.4 경기장·카메라
- **FR-14** 경기장 크기는 고정이다. 가장자리 밖은 낭떠러지이며 난간이 없다.
- **FR-15** 가장자리가 화면에서 또렷하게 보여야 한다 (바닥 색 대비, 가장자리 표시 등).
- **FR-16** 카메라는 비스듬히 위에서 내 캐릭터를 따라간다(쿼터뷰). 플레이어가 카메라를 돌리지 않으며, 가장자리 근처에서는 낭떠러지가 화면 안에 보여야 한다.
- **FR-17** 입장 위치는 가장자리와 다른 플레이어에게서 떨어진 곳으로 정한다.
- **FR-18** 입장 직후 **3초 동안 무적**이며 반투명하게 표시한다. 무적 중에 공격하면 무적이 바로 풀린다.

### 4.5 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 (8방향) | ← ↑ → ↓ | 왼쪽 가상 조이스틱 |
| 달리기 | Shift 누르는 동안 | 조이스틱을 끝까지 밀기 |
| 점프 | Space | 점프 버튼 |
| 왼손 펀치 | A | 버튼 |
| 오른손 펀치 | S | 버튼 |
| 발차기 | D | 버튼 |
| 가드 | F 누르는 동안 *(가정)* | 버튼 누르는 동안 |
| 잡기·던지기 | G *(가정)* | 버튼 |
| 이모트 | 1 ~ 4 *(가정)* | 이모트 버튼 → 선택 |

- **FR-19** 이동 방향은 **화면 기준**이다 (↑ = 화면 위쪽).
- **FR-20** 캐릭터는 이동하는 방향을 바라보고, 공격은 바라보는 방향으로 나간다.
- **FR-21** *(제안)* 키보드는 8방향뿐이라 비스듬히 선 상대를 맞히기 어렵다. 공격할 때 가까운 상대 쪽으로 몸을 살짝 틀어 주는 보정을 둔다.
- **FR-22** 점프는 한 번만 할 수 있다 (공중 재점프 없음).
- **FR-23** 처음 입장하면 조작법을 안내하고, 게임 중에도 다시 볼 수 있다.

### 4.6 전투
- **FR-24** HP는 100에서 시작하고 자연 회복은 없다. *(가정)*
- **FR-25** 공격이 맞으면 HP가 줄고, 공격자 반대 방향으로 **공격별 고정 거리**만큼 밀려나며, 짧게 경직된다. 타격 이펙트·효과음·짧은 멈춤으로 손맛을 준다.
- **FR-26** 공격마다 속도·사거리·피해·넉백이 다르다 (§5 초기값).
- **FR-27** **돌진 공격**: 달리는 중에 공격 키를 누르면 나간다. 일반 공격보다 피해와 넉백이 크지만 빗나가면 빈틈이 크다.
- **FR-28** **날아차기**: 점프 중에 D를 누르면 나간다. 피해와 넉백이 크고 착지 후 빈틈이 있다. 점프 중 A·S는 일반 펀치와 같다.
- **FR-29** **가드**: 누르고 있는 동안 정면에서 오는 공격의 피해와 넉백을 크게 줄인다. 가드 중에는 움직일 수 없다. *(제안)* 옆이나 뒤에서 오는 공격은 막지 못한다.
- **FR-30** **잡기**: 바로 앞 상대를 잡고, 잡은 상태에서 방향키로 정한 쪽으로 던진다. 정해진 시간 안에 방향을 고르지 않으면 바라보는 방향으로 던진다. 던지기는 넉백이 가장 크다.
- **FR-31** **상성**: 잡기는 가드를 뚫고, 잡는 동작 중에 맞으면 잡기가 끊긴다. → *공격 > 잡기 > 가드 > 공격*
- **FR-32** 여러 명에게 둘러싸여 계속 맞기만 하고 아무것도 못 하는 상황(무한 경직)을 막는 장치가 있어야 한다.
- **FR-33** 팀이 없으며 모든 플레이어가 서로 적이다.

### 4.7 탈락
- **FR-34** HP가 0이 되면 쓰러지는 연출 후 경기장에서 사라진다.
- **FR-35** 경기장 밖으로 떨어져 일정 높이 아래로 내려가면 HP와 상관없이 **즉시 탈락**한다.
- **FR-36** 낙사하기 전 **5초 안에** 마지막으로 때리거나 던진 사람이 킬을 얻는다. 그런 사람이 없으면 '자멸'로 처리한다.
- **FR-37** **60초 동안 입력이 없으면** 자리 비움으로 퇴장시킨다.
- **FR-38** 연결이 끊기면 캐릭터를 경기장에서 바로 없앤다.
- **FR-39** 탈락하면 결과 화면을 보여준다: 생존 시간, 킬 수, 탈락 원인(누구에게 졌는지 / 낙사 / 자멸 / 자리 비움), 경기장에서 오른 최고 순위.
- **FR-40** 결과 화면에서 '다시 하기'를 누르면 캐릭터 선택 화면으로 가고 새 닉네임을 받는다.

### 4.8 화면 정보 (HUD)
- **FR-41** 모든 캐릭터 머리 위에 닉네임과 HP 바를 표시한다.
- **FR-42** 내 HP, 킬 수, 생존 시간을 화면 구석에 늘 표시한다.
- **FR-43** **킬 피드**: 최근 탈락 소식을 몇 초 동안 보여준다. 원인에 따라 문구가 다르다.
  - 「조용한 황소의 기상」님이 「푸른 달빛은 그림자 속에」님을 쓰러뜨렸습니다
  - 「조용한 황소의 기상」님이 「백색 매와 함께 춤을」님을 경기장 밖으로 날려버렸습니다
  - 「용감한 늑대의 기상」님이 발을 헛디뎠습니다 (자멸)
- **FR-44** **순위표**: 지금 경기장에 있는 플레이어를 킬 수로(같으면 생존 시간으로) 줄 세워 상위 5명과 내 순위를 보여준다.

### 4.9 연습용 봇
- **FR-45** 경기장에 사람이 1~3명뿐이면 봇을 넣어 모두 4명이 되게 한다. *(가정)*
- **FR-46** 사람이 들어오는 만큼 봇이 나간다. 16명 정원에서는 사람이 봇보다 우선이다.
- **FR-47** 봇도 인디언식 이름을 쓰지만 🤖 표시로 사람과 구분한다.
- **FR-48** 봇은 이동·공격·가드를 하며 일부러 떨어지지 않는다. 난이도는 연습 상대 수준이다.

### 4.10 이모트
- **FR-49** 이모트는 4종이다 (예: 손 흔들기, 도발, 춤, 승리 포즈 — 구성 미정).
- **FR-50** 이모트 중에도 맞을 수 있고, 이동이나 공격을 입력하면 바로 취소된다.
- **FR-51** 채팅은 넣지 않는다 (D8).

### 4.11 모바일
- **FR-52** 가로 화면 전용이다. 세로로 들고 있으면 돌려 달라고 안내한다.
- **FR-53** 왼쪽에 조이스틱, 오른쪽에 버튼(왼손 펀치·오른손 펀치·발차기·점프·가드·잡기·이모트)을 둔다.
- **FR-54** 버튼은 엄지로 누르기 편한 크기와 위치여야 한다.
- **FR-55** PC인지 모바일인지 자동으로 알아내 알맞은 조작 안내를 보여준다.
- **FR-56** PC 사용자와 모바일 사용자는 같은 경기장에서 함께 싸운다.

## 5. 초기 밸런스 값 *(가정 — 플레이테스트로 조정)*

| 동작 | 입력 | 피해 | 속도 | 사거리 | 넉백 |
|---|---|---|---|---|---|
| 왼손 펀치 (잽) | A | 5 | 매우 빠름 | 짧음 | 짧음 |
| 오른손 펀치 (스트레이트) | S | 8 | 빠름 | 짧음 | 중간 |
| 발차기 | D | 12 | 느림 | 김 | 큼 |
| 돌진 공격 | 달리는 중 공격 | 12 | 보통 | 중간 | 큼 |
| 날아차기 | 점프 중 D | 14 | 느림 | 김 | 큼 |
| 던지기 | 잡기 → 방향 | 10 | — | 바로 앞 | 가장 큼 |

| 항목 | 초기값 |
|---|---|
| HP | 100, 자연 회복 없음 |
| 경기장 크기 | 정사각형 약 24m × 24m (16명 기준) |
| 가드 | 정면 공격의 피해·넉백 대폭 감소 |
| 입장 무적 | 3초 |
| 낙사 킬 인정 | 마지막 타격 후 5초 |
| 자리 비움 퇴장 | 입력 없이 60초 |
| 봇 투입 | 사람이 1~3명일 때 4명까지 채움 |

> 넉백은 HP와 무관하게 늘 같은 거리다 (D6). 그래서 낙사는 주로 가장자리 근처에서 발차기·돌진·날아차기·던지기로 일어난다.

## 6. 비기능 요구사항

| ID | 분류 | 요구사항 |
|---|---|---|
| NFR-01 | 성능 (PC) | 16명이 한 화면에서 싸워도 내장 그래픽 노트북에서 60fps를 목표로 하고, 최소 30fps를 지킨다 |
| NFR-02 | 성능 (모바일) | 중급 스마트폰에서 30fps 이상 |
| NFR-03 | 로딩 | 시작 화면 3초 이내, 경기장 입장까지 10초 이내 (일반 가정용 인터넷·LTE 기준). 첫 다운로드 20MB 이하 목표 |
| NFR-04 | 반응성 | 왕복 지연 150ms까지 정상 플레이: 내 캐릭터는 입력에 바로 반응하고, 다른 캐릭터는 끊김 없이 움직인다 |
| NFR-05 | 공정성 | 피해·HP·위치·탈락 판정은 클라이언트를 변조해도 바꿀 수 없다 |
| NFR-06 | 남용 방지 | 같은 IP의 동시 접속 수 제한, 비정상적으로 잦은 입력 차단, 접속 시도 횟수 제한 |
| NFR-07 | 확장성 | 경기장 수를 늘려 동시 접속자 증가에 대응한다 (목표 총 동시 접속자 수는 미정) |
| NFR-08 | 호환성 | 데스크톱 Chrome·Edge·Firefox·Safari 최신 버전, iOS Safari·Android Chrome. 3D를 지원하지 않는 브라우저에는 안내를 보여준다 |
| NFR-09 | 사용성 | 첫 방문부터 경기장 입장까지 클릭 3번 이내. UI는 한국어 |
| NFR-10 | 개인정보 | 개인정보를 수집하지 않는다 (로그인·채팅 없음) |
| NFR-11 | 에셋 라이선스 | 3D 모델·애니메이션·효과음은 웹 공개 서비스에 쓸 수 있는 라이선스여야 한다 |
| NFR-12 | 운영 | 현재 접속자 수와 경기장 수를 확인할 수 있다 |

## 7. 사용자 스토리 & 인수 조건

**US-01 바로 싸우기** — 방문자로서, 가입 없이 바로 싸움에 들어가고 싶다.
- [ ] 시작 → 캐릭터 선택 → 입장, 클릭 3번 이내로 경기장에 들어간다.
- [ ] 로그인이나 개인정보 입력 화면이 없다.
- [ ] 빈자리가 있는 경기장 중 사람이 가장 많은 곳에 배정되고, 모두 차 있으면 새 경기장이 열린다.

**US-02 캐릭터와 이름** — 마음에 드는 캐릭터와 재미있는 이름으로 들어가고 싶다.
- [ ] 캐릭터 4~6종을 3D로 돌려 보며 고를 수 있다.
- [ ] 이름이 자동으로 정해지고 🎲로 다시 뽑을 수 있다.
- [ ] 받침에 맞는 조사가 붙는다 (예: '태양과', '나무는', '달빛은').

**US-03 움직이기** — 경기장을 자유롭게 움직이고 싶다.
- [ ] 방향키로 8방향 이동하고, 두 키를 같이 누르면 대각선으로 간다.
- [ ] Shift를 누르는 동안 걷기보다 확실히 빠르게 달린다.
- [ ] Space로 점프하며, 공중에서 다시 점프할 수 없다.
- [ ] 모바일에서는 조이스틱을 끝까지 밀면 달린다.

**US-04 때리기** — 상대를 때려 HP를 깎고 밀어내고 싶다.
- [ ] A·S·D를 누르면 왼손 펀치·오른손 펀치·발차기가 나간다.
- [ ] 맞은 상대는 HP가 줄고, 공격별로 정해진 거리만큼 밀려나며, 피격 연출이 보인다.
- [ ] 경기장 안 모든 플레이어 화면에서 같은 결과로 보인다.

**US-05 연계 공격** — 달리기와 점프를 공격에 섞고 싶다.
- [ ] 달리는 중에 공격하면 돌진 공격이 나가고 일반 공격보다 멀리 밀어낸다.
- [ ] 점프 중에 D를 누르면 날아차기가 나간다.

**US-06 막기** — 공격을 막아 버티고 싶다.
- [ ] F를 누르는 동안 정면 공격의 피해와 넉백이 크게 준다.
- [ ] 가드 중에는 움직일 수 없고, 잡기는 막지 못한다.

**US-07 잡아서 던지기** — 상대를 잡아 원하는 방향으로 던지고 싶다.
- [ ] G로 바로 앞 상대를 잡고, 방향키로 정한 쪽으로 던진다.
- [ ] 가드 중인 상대도 잡힌다.
- [ ] 잡는 동작 중에 맞으면 잡기가 끊긴다.
- [ ] 가장자리에서 밖으로 던지면 상대는 떨어져 탈락한다.

**US-08 탈락과 재시작** — 졌을 때 결과를 확인하고 다시 도전하고 싶다.
- [ ] HP가 0이 되면 쓰러지고 경기장에서 사라진다.
- [ ] 경기장 밖으로 떨어지면 HP와 상관없이 바로 탈락한다.
- [ ] 결과 화면에 생존 시간·킬 수·탈락 원인이 나온다.
- [ ] '다시 하기'를 누르면 캐릭터 선택 화면으로 가고 새 이름을 받는다.

**US-09 상황 파악** — 누가 강하고 무슨 일이 일어났는지 알고 싶다.
- [ ] 모든 캐릭터 머리 위에 닉네임과 HP 바가 보인다.
- [ ] 누가 누구를 쓰러뜨렸는지 킬 피드로 보인다. 낙사는 5초 안에 마지막으로 때린 사람의 킬이 된다.
- [ ] 순위표에서 상위 5명과 내 순위를 본다.

**US-10 안전한 입장** — 들어가자마자 당하고 싶지 않다.
- [ ] 가장자리와 다른 플레이어에게서 떨어진 곳에서 시작한다.
- [ ] 입장 후 3초 동안 무적이고 반투명하게 보인다. 무적 중에 공격하면 무적이 풀린다.

**US-11 혼자여도 연습** — 사람이 적어도 바로 싸워 보고 싶다.
- [ ] 사람이 1~3명뿐이면 봇이 채워져 모두 4명이 된다.
- [ ] 봇은 🤖 표시로 구분된다.
- [ ] 사람이 들어오면 그만큼 봇이 줄어든다.

**US-12 모바일로 플레이** — 휴대폰으로도 똑같이 싸우고 싶다.
- [ ] 가로 화면에서 조이스틱과 버튼으로 PC와 같은 모든 동작을 할 수 있다.
- [ ] PC 사용자와 같은 경기장에서 싸운다.

**US-13 이모트** — 말 대신 동작으로 감정을 표현하고 싶다.
- [ ] 1~4 키(모바일은 이모트 버튼)로 이모트 4종을 쓴다.
- [ ] 이모트 중에도 맞을 수 있고, 이동이나 공격을 입력하면 바로 취소된다.

## 9. 가정 *(확인 필요)*
- **A1** UI 언어는 한국어만 지원한다.
- **A2** HP는 100이고 자연 회복은 없다.
- **A3** 아트 스타일은 로우폴리 캐주얼이다 (무료 에셋을 구하기 쉬움).
- **A4** 키 배정 기본안: 가드 F, 잡기 G, 이모트 1~4.
- **A5** 경기장은 1종이며 장애물 없는 평평한 바닥이다.
- **A6** 효과음은 넣고 배경음악은 선택 사항이다. 음소거 버튼을 제공한다.
- **A7** 게임패드는 지원하지 않는다.

## 10. 리스크와 고려 사항
- **R1 지연과 타격 판정**: 근접 격투는 네트워크 지연에 민감하다 ("분명 맞았는데?"). 설계 단계에서 판정 방식을 가장 먼저 검토해야 한다.
- **R2 16명 난투의 불쾌함**: 집단 공격, 입장 직후 공격, 무한 경직 → FR-17·18·32로 대응.
- **R3 애니메이션 양**: 걷기·달리기·점프, 펀치 2종, 발차기, 돌진, 날아차기, 가드, 잡기, 던지기, 잡힘, 피격, 쓰러짐, 이모트 4종 등 20종 안팎이 필요하다. 캐릭터 4~6종이 같은 애니메이션을 함께 쓸 수 있어야 작업량을 감당할 수 있다.
- **R4 모바일**: 버튼이 7개라 화면이 붐비고, 저사양 기기 성능이 걱정된다.
- **R5 서버 운영비**: 실시간 대전이라 항상 켜져 있는 서버가 필요하다. 정적 호스팅만으로는 안 된다.
- **R6 '인디언식 이름' 표기**: 해외에 공개하면 문화적 논란이 생길 수 있다. 화면 표기는 '자연 이름' 같은 대체 표현도 검토한다.
- **R7 익명 서비스 남용**: 여러 탭 접속, 자동화 접속 → NFR-06으로 대응.
