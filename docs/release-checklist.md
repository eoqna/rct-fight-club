## 4. 공개 전에 정할 것

- ❗ **정식 도메인** — 지금은 무료 하위 도메인으로 스테이징한다. 바꿀 때는 `.env`의 `SITE`·`ALLOWED_ORIGINS`를 고치고 다시 띄우면 Caddy가 새 인증서를 받는다.
- ❗ **휴대폰으로 들어온 사람 안내** — 모바일 조작이 없어 휴대폰에서는 입장해도 움직일 수 없다. "PC 키보드로 플레이해 주세요" 안내를 띄울지.
- ❗ **서비스 이름** (가칭 Fight Club, 요구사항 열린 질문 1)
- ❗ **플레이테스트 결과 반영** — 조정값과 일정

## 5. 되돌리기와 장애 때

| 상황 | 할 일 |
|---|---|
| 새 릴리스에 문제 | `deploy/rollback.sh ubuntu@<IP>`로 목록을 보고 이전 릴리스로 (이미지가 남아 있어 바로 바뀐다) |
| 게임 서버가 죽음 | 컨테이너가 스스로 다시 뜬다 (`restart: unless-stopped`, 헬스 체크). 로그: `deploy/logs.sh` |
| 느려짐 | `/admin`에서 틱 처리 p95·CPU 확인 → Lightsail CPU 그래프(버스트) → 한 단계 큰 요금제 |
| 인증서 문제 | `deploy/logs.sh ubuntu@<IP> web` — DNS가 고정 IP를 가리키는지, 방화벽 80·443이 열렸는지 |
